# 小红书爆款笔记生成器（生成即用·笔记）使用说明

## 适用场景
按赛道与人设，直接生成小红书笔记正文+封面提示词+标题备选。

## 对话示例
用户：「写篇美妆护肤笔记，亲测人设，300字」
→ agent 弹窗：选 ①成品 / ②半填充 / ③模板
→ agent 弹窗：填领域参数（赛道、人设、字数）
→ agent 直接落盘：笔记正文（带emoji分段+话题标签）+ 3条标题备选 + 封面图提示词

## 模式区别
- 成品：给真实数据，直接出可投稿/可运行文件。
- 半填充：部分数据+占位符，可运行待补。
- 模板：纯骨架+说明，自行填。

## 输出文件
笔记正文（带emoji分段+话题标签）+ 3条标题备选 + 封面图提示词。
